# Modelo de registro restrito de conferência

Modelo vazio. **Não preencher este arquivo no repositório com dados reais.** Copiar a estrutura para o sistema de atendimento restrito aprovado. Não anexar documentos, copiar números ou incluir dados do menor em assunto de e-mail. Conservar revisões do atendimento e aplicar a tabela de retenção aprovada.

| Campo | Preencher no atendimento restrito |
| --- | --- |
| Referência aleatória do atendimento | |
| Referência anterior, se reavaliação | |
| Versão do procedimento e da política aplicadas | |
| Identificador interno da conta e do vínculo, quando aplicável | |
| Etapa: conta adulta / vínculo / contestação / revogação / direito do titular | |
| Operador e revisor, se houve encaminhamento | |
| Data/hora da conferência e método aprovado | |
| Controle da conta demonstrado / não demonstrado | |
| E-mail confirmado / não confirmado | |
| Identidade e maioridade: suficiente / insuficiente / não se aplica | |
| Relação legal e faixa: suficiente / insuficiente / não se aplica | |
| Categoria da evidência visualizada, sem cópia nem número | |
| Consentimento atual conferido: sim / não / não se aplica | |
| Decisão: pendente / aprovar / não aprovar / encaminhar | |
| Fundamentação mínima, sem dados excedentes | |
| Referência registrada no painel e resultado confirmado | |
| Orientação/comunicação ao titular e canal autorizado | |
| Próxima revisão ou motivo de encerramento | |
| Categoria e evento inicial de retenção aprovados | |
| Descarte previsto, execução e exceção fundamentada, se aplicável | |

Critérios insuficientes não devem ser marcados como conferidos. Não registrar conclusão fictícia ou se passar pelo responsável para consentir. Não usar a atestação administrativa apenas para encerrar uma pendência sem conferência. Consultar [POP-RESP-01](procedimento-conferencia-responsaveis-20261030.md).
