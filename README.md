# Projetos Apogee

Este repositório contém o site Apogee em `make-it-fly-current/`, o Radar Acadêmico em `radar-academico/` e uma aplicação histórica na raiz.

O [PRD geral da Apogee](docs/apogee-prd.md) consolida a proposta de comunidade, entrada gratuita e direitos de acesso, aprovada em 14/11/2026, com páginas em prévia local. O [PRD do Radar](docs/radar-prd.md) mantém a especificação especializada do catálogo e da coleta.

Para desenvolvimento local, consulte o README e o `AGENTS.md` da aplicação desejada. A hospedagem do site Apogee usa a VPS; o procedimento e os limites de publicação estão em `docs/apogee-routine-vps-deploy.md`.
